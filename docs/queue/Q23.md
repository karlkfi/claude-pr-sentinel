# Assert every test suite is listed in CLAUDE.md

Nothing checks the Testing section against `tests/`, so it drifts silently:
Q20 was filed at four-listed-of-eight and had reached four-of-eleven by the
time it was worked (measured 2026-08-19 on f6d140d). Both gaps were found by
a human reading the file, which is the only detector there is.

`test_wiring.py` already has the shape: its
`test_every_env_var_is_in_the_configuration_table` gates the README
Configuration table the same way. So this is one more test beside it — glob
`tests/test_*.py`, assert each is named in CLAUDE.md, and assert the reverse
so a deleted suite loses its line too.

The trade-off to weigh before writing it: this couples the prose to the test
tree, so adding a suite stops being a one-file change. That is the intent, but
it is a real cost and the reason to decide rather than assume — reverse this
item if the answer is that the coupling is worse than the drift.
