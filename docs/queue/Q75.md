# The --delete / --tags check reads option values and misses abbreviations

`classify_command` drops a branch deletion or a tag push by testing whether
`--delete`, `-d` or `--tags` appears anywhere in the command's words. That
membership test fails in both directions.

**It reads an option's value as a flag**, which is the silent direction.
`git push -o -d origin claude/foo` is a real push carrying the push option `-d`,
and it classifies silent, so the PR it updated goes unwatched. **It misses the
spellings git accepts**, which is noise. `--del` is a deletion (git takes any
unambiguous prefix of a long option), and `-fd` is a deletion inside a
short-option cluster. Both still nudge.

Measured 2026-11-10 by driving `detect_action` on the Q63 branch, with a
working directory whose `origin` is a forge. Git 2.55.0 against a scratch bare
repo ran `-fd` and `--del` as deletions:

| Command | Classified | Should be |
|---|---|---|
| `git push origin claude/foo` (control) | `git_push` | `git_push` |
| `git push -o -d origin claude/foo` | `None` | `git_push` |
| `git push --push-option -d origin claude/foo` | `None` | `git_push` |
| `git push -o --tags origin claude/foo` | `None` | `git_push` |
| `git push --del origin claude/foo` | `git_push` | `None` |
| `git push -fd origin claude/foo` | `git_push` | `None` |
| `git push --push-opt -n origin claude/foo` | `None` | `git_push` |

The last row is the Q63 fix's own walk, `_sends_nothing`, which has the same
gap one level down. It skips an option's value, stops a cluster at `o` and stops
at `--`, but it recognises a value-taking option only by its full name, and only
`--dry-run` by its abbreviations. Git 2.55.0 reads `--push-opt` as
`--push-option` and takes `-n` as its value, so this is a real push: the bare
test remote refused it with "the receiving end does not support push options".
The walk reads the `-n` as a dry run.

The fix is one walk that resolves every long option by unique prefix, against
the names `GIT_VALUE_FLAGS` and `PUSH_VALUE_FLAGS` already list, and that
carries `--delete`, `-d` and `--tags` as well as the Q63 flags. The Q63 work
left `--delete` / `--tags` alone because it was outside that row's scope. Found
by the hook-stream reviewer's probes for Q63. The `-o -d` and `--push-opt -n`
cases are contrived, which is why this ranks below the silent-direction rows.
