# Read a shared cross-plugin overlap ignore list

`PR_SENTINEL_OVERLAP_IGNORE` and `BRANCH_GUARD_OVERLAP_IGNORE` now parse the
same way (#79), so a list copies between them intact — but it is still written
twice, and the two copies drift the moment one repo adds a merge-driver-owned
path to one of them. Option 1 of that issue: fall back to a shared
`CLAUDE_OVERLAP_IGNORE` when the house-prefixed variable is unset, keeping each
plugin's own prefix as the override. `PR_SENTINEL_BASE_REF` /
`BRANCH_GUARD_BASE_REF` split the same way and would take the same treatment.

Deferred because it buys nothing until branch-guard reads the shared name too,
and that plugin shipped its half in v1.8.0.

**Event:** a repo keeps the same ignore list (or base ref) in both plugins and
the two copies are seen to disagree.
