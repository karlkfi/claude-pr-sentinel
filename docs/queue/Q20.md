# List every test suite in CLAUDE.md's Testing section

It names four; `tests/` holds eleven. `test_alloc.py`,
`test_friction_report.py`, `test_guard.py`, `test_overlap.py`,
`test_queue_store.py`, `test_stop_hook.py` and `test_watchers.py` are
unlisted, so a new guard or backlog test has no pointer to its file.

Filed when the gap was four-of-eight; the store migration and the queue-id
work have since added two more suites, so re-count before editing rather than
trusting this list.
