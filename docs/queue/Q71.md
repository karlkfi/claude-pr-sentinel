# Audit PRIVACY.md's existing absolute negatives for their evidence

`docs/development/privacy-disclosures.md` now requires a disclosure that says
something did **not** happen to name what established it: a measurement with
its date, or the test that enforces it. The rule was written for disclosures
written or changed from Q55 on, so the sentences already in `PRIVACY.md`
predate it.

## Measured

2026-11-09 at `274a6df`. This grep matched 48 lines of `PRIVACY.md`:

    grep -n -i -E "writes nothing|nothing else|inspects nothing|reads nothing|\*\*none\*\*|\bnever\b|no network access|the only component|only one|\bnothing\b|\bno telemetry\b|not requested" PRIVACY.md

That is a sample, not a census or a ceiling. A first draft of this row used
the grep without its last three terms, matched 31 lines, and called that a
ceiling. Review of #181 found eleven negatives it missed, the clearest being
"no analytics, no telemetry, and no data collection" in "Data we collect".
Phrasings like "no process table" or "is not opened" escape the wider grep too,
so the audit reads the file rather than the grep's output.

Not every match is a negative that needs evidence. Some are scoping words
("never a blocked command"), and some already carry it: the `compare` bullet's
"106 KB for a seven-commit comparison, measured 2026-09-18". Others do not.
"Runs **entirely locally with no network access**" appears five times, and
"writes nothing to disk" sits in five sections, with nothing beside either
saying what established it. None of the 48 has been classified yet. That is
the first step of this item.

## What to do

For each negative, one of three things. Name the test that already enforces
it, where one exists and the claim is about what the code requests rather
than what a response carries. Measure it and write the measurement down. Or
reword it into what the code positively does. "No network access" is the one
worth deciding first, because it covers five components. The probe that would
back it is an import-and-run of each Python component with its socket access
patched to raise.

## Why it ranks here

Nothing is known to be false. The two negatives found false so far, the
watcher's "writes nothing to disk" and the migration helper's "the only
component that does", were both repaired in the branch that falsified them.
The cost lands on a reader who takes the rest at face value.
